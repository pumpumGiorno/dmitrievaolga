# Фотографии объектов

Каждая папка соответствует ID объявления на Авито (последние цифры в ссылке).

Как добавить фото объекта:

1. Откройте объявление на Авито и сохраните фотографии.
2. Положите их в папку с ID объекта, например `public/objects/7944703179/`.
3. Назовите файлы по порядку: `1.jpg`, `2.jpg`, `3.jpg` — первый файл станет обложкой карточки.

Поддерживаемые форматы: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.
Сайт подхватывает фото автоматически — код менять не нужно.
Пока фото нет, показывается нейтральная заглушка по типу объекта.
